# 03 - Features

# Purpose

This document defines the functional capabilities provided by the Money Manager application.

Features describe what users can accomplish within the application. They are independent of user interface, navigation, implementation, and business logic.

Business behavior is defined in **02-business-rules.md**.

---

# Feature Overview

| Module           | Description                                    |
| ---------------- | ---------------------------------------------- |
| Dashboard        | View overall financial health.                 |
| Accounts         | Manage financial accounts.                     |
| Credit Cards     | Manage credit card accounts and bill payments. |
| Transactions     | Record financial activities.                   |
| Categories       | Organize transactions.                         |
| Recurring Rules  | Automate recurring transactions.               |
| Reports          | Analyze financial data.                        |
| Search & Filters | Locate and analyze records.                    |
| Settings         | Configure application preferences.             |

# Future Features

The following features are intentionally excluded from Phase 1.

* Authentication
* Cloud synchronization
* Bank synchronization
* Investment tracking
* Loan management
* Budgeting
* Financial goals
* Multi-currency support
* OCR receipt scanning
* AI-generated financial insights
* Shared or family accounts
